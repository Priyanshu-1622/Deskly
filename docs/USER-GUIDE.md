# Start using Deskly

Deskly's current release target is a Windows public beta. Until an approved installer is published, run the source using the README instructions. macOS and Linux remain unverified targets.

## First session

1. Set your name, company and project folder in the first-run wizard. Use a disposable test folder for your first real task.
2. Explore in demo mode. Demo task output is simulated; it does not prove a provider is connected.
3. Walk with WASD, look with the mouse and interact with E. Escape closes a panel or pauses. Click the office view if your mouse is not captured. Press G for the map and F1 to replay the introduction.
4. Open **Team & AI keys**. Choose a provider for an employee, configure its model/access and use its connection check. Hosted checks can incur a small charge. Save the settings before assigning work.
5. Walk up to the employee, press E and assign a small task. Keep file-write approvals enabled while learning. Review the entire requested content or command before approving it.
6. Use Tab to review progress, permissions, errors and results. Inspect the files in your project folder before treating the work as complete. You can stop a task or resume interrupted work from its card.

## Meetings and shared memory

Press C/M, choose a room and people, then call them. Press C/M again for the shared conversation. Posting saves a message without an AI request. Choose speakers for a discussion round; each sees the founder message and earlier replies. Stop ends the current round. Save a shared decision only when it is confirmed; it becomes verified memory for the participants in the current project. Other suggestions stay in conversation history.

To recall everyone at night, use **Tab → Team → Call everyone back · keep here**. They stay until you send them home, including across restarts. Idle presence consumes no AI tokens.

## Boards and navigation

G opens the map: search, choose a destination, and follow its route. Interact with a whiteboard using E or open it from the laptop/map. Drag card headers to move cards and corners to resize them. Use Export backup before clearing important notes. Boards currently belong to rooms on your device, not individual projects.

## If something fails

- Missing API key: configure and save the employee's access, then check the connection. Installed CLI providers need a working installed sign-in.
- Provider/model/quota error: check the saved model and account allowance. A different employee can have a different provider. Do not retry indefinitely.
- Low frame rate: select Low graphics quality, keep automatic performance balancing on, and close other GPU-heavy programs. There is no published minimum hardware target yet.
- Stuck controls: close the panel with Escape, click the office and stand up if seated. Include the exact steps in a bug report if it persists.
- Damaged saved data: read the recovery notice before erasing anything. The app preserves damaged originals. Project files are separate from app data.

For a report, save diagnostics in **Settings → Privacy & data** and describe the steps, expected result and actual result. Review screenshots for private information. Diagnostic reports are safe aggregate data; raw audit exports may contain private project text.
